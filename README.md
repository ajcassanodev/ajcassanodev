## Flask Site

This repository includes a simple Flask application located in `flask_site/`.
The app allows users to register, log in, manage their profile and access a personal dashboard.

### Running locally

1. Create a virtual environment and install dependencies:
   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r flask_site/requirements.txt
   ```
2. Start the app:
   ```bash
   python flask_site/app.py
   ```
3. Navigate to `http://localhost:5000` in your browser.
